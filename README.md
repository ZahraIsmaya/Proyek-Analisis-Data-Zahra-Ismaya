## Setup Environment
python -m venv venv

**Windows:**
venv\Scripts\Activate.ps1

**Mac/Linux:**
source venv/bin/activate

pip install -r requirements.txt

## Run Streamlit App
Dataset akan otomatis terdownload saat pertama kali app dijalankan.
streamlit run dashboard/dashboard.py

## Live Dashboard
Cek link dashboard di `url.txt`
